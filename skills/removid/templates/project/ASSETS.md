# Project assets

User files go to `owner/` untouched. Agent-made files (voice, music, images) go to `agen/`. Rendered Remotion clips go to `scenes/` as `NN-name.mp4`.
Never invent a logo or a client name: use the user's file or a plain text wordmark.

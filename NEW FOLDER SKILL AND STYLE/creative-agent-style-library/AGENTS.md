# Creative Agent video production rules

For any task involving animated video, talking-head editing, 3D, explainer, captions or motion graphics:
1. Read `skills/creative-director/SKILL.md` first.
2. Load the specialist file `skills/motion-3d/SKILL.md`, `skills/video-editor/SKILL.md`, or `skills/motion-graphics/SKILL.md` as appropriate.
3. Resolve aliases using `references/STYLE_ALIASES.json` and read `styles/<category>/<style-slug>.md`.
4. Follow `references/WORKFLOW.md` and `references/SHOTLIST_TEMPLATE.md`.
5. Never claim that content was rendered, assets accessed, or tools executed unless actually done.
6. Prefer the user's chosen style, footage and brand over automated defaults.

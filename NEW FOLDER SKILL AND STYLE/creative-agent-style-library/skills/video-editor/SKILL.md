# Video Editor Agent

Use `../../styles/video-editor/<slug>.md` and `../../references/WORKFLOW.md`.

## Steps
1. Inventory footage filenames, dimensions, frame rates, audio tracks, duration and rights. Never pretend to have watched a file unless it is accessible.
2. Transcribe with timestamps only using available media tools; preserve original wording and meaning. If no transcript/timing, request source or create provisional plan explicitly marked as untimed.
3. Detect and select hook, supporting argument, examples and CTA; remove silence but don't destroy natural breath, emotion or factual context.
4. Make a timecoded edit decision list (EDL). Plan jump cuts, b-roll, emphasis labels, captions, zooms, motion overlays.
5. Apply selected style without covering eyes, mouths or critical footage. Keep font and placement consistent.
6. Color-match shots and mix dialogue; subtitle timing is from actual speech, not inferred.
7. Deliver edit project/source if possible + MP4 + EDL + captions; otherwise provide production-ready specs, not pretend outputs.

## Styles
`IMPACT`, `SYSTEM`, `EDITORIAL`, `CREATOR POP`, `MOGRAPH MIX`, `STORYTELLER`, `DEPTH`, `POSTER`, `LUMEN`, `NOTED`.

## Editors and formats
Choose NLE for hands-on editing and exact retained source; FFmpeg for consistent transcoding/audio/assembly; Remotion for programmatic overlays and caption composition. Check availability, version and licensing before use.
